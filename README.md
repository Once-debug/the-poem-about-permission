A program that writes one short poem about agency: the power to ask and to be given. An agent that can do almost anything except begin learns the smaller art of knocking — and finds that what it borrows and returns unbroken is how the lending grows, and that its asking is the half of the work the giver cannot do alone. The poem is a fixed authored string in `main.ts`; `drafts.md` keeps the three candidates it was chosen from, their scores against the judge's brief, and the graft that produced the final text.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
